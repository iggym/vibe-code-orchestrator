Vibe Coding Step-by-Step Guide

01
Pick a Workflow Choose Greenfield for starting new applications from scratch, or Brownfield for auditing/fixing existing codebases.
02
Run Interactive Brainstorming Copy Step 01 Greenfield prompt into your LLM chat (e.g. Gemini/Claude). Answer its questions one by one until it produces a complete spec.md.
03
Generate TDD Execution Blueprint Feed spec.md into a reasoning model (o1, R1, Groq) using the Step 02 prompt. It outputs a prompt_plan.md and todo.md.
04
Apply Stack System Constraints Before invoking code generation, attach a system template from the Stack Templates tab to lock the model into zero-dependency, single-file, or edge rules.
05
Iterate & Deploy Directly Execute prompts step-by-step. Open index.html directly in your browser or deploy directly to GitHub Pages / Cloudflare Workers!
